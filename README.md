# Sakshi Singh — Developer Portfolio

A multi-page, dark portfolio starter with an elegant amber accent, persistent sidebar navigation, and Home, Experience, Skills, Projects, and Contact pages.

## Run locally

```sh
npm install
npm run dev
```

The page content in `src/App.tsx` is starter copy and sample project data. Replace it with your own experience, project details, email, and social profile URLs as you personalize the design.
